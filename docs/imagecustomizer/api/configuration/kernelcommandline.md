# kernelCommandLine type

Options for configuring the kernel command-line.

The location where Image Customizer updates the kernel command-line depends on
the base image:

- If the base image contains UKIs, then Image Customizer keeps track of the
  kernel command-line args internally and then uses the updated args when
  recreating the UKIs.

- If the `grub.cfg` file contains the string `automatically generated by grub`,
  then Image Customizer assumes `grub2-mkconfig` is being used and will update
  the `/etc/default/grub` file.

- Otherwise, Image Customizer updates the `grub.cfg` file directly.

Image Customizer understands the parsing rules of `grub.cfg` files and
should correctly handle things such as quoted strings, escaped characters, and
escaped newlines.

Added in v0.3.

## replace [[kernelCommandLineReplace](./kernelcommandlinereplace.md)[]]

A list of operations to replace/update the Linux kernel command-line arguments.

These replace operations are run in the order that they are specified. Later
replace operations can change the values added in earlier replace operations.
The replace operations run before the
[extraCommandLine](#extracommandline-string) arguments are added.

This field is not supported in the
[iso.kernelCommandLine](./iso.md#kernelcommandline-kernelcommandline) and
[pxe.kernelCommandLine](./pxe.md#kernelcommandline-kernelcommandline) fields.

Added in v1.8.

## extraCommandLine [string[]]

Additional Linux kernel command line options to add to the image.

When modifying the `/etc/default/grub` file, then the arguments will be added to
`GRUB_CMDLINE_LINUX_DEFAULT`.

Example:

```yaml
os:
  kernelCommandLine:
    extraCommandLine:
    # Print the system logs to the serial port instead of to the screen, so that they
    # can be programmatically collected.
    - console=tty0
    - console=ttyS0
```

Added in v0.3.
